# MeetFlow

> 여러 회의를 하나로 이어서, 프로젝트 흐름을 놓치지 않게 붙잡아주는 대학생 팀용 AI

**🔗 [데모 바로가기](https://suming030.github.io/meetflow/)** — 구글 계정으로 로그인하면 바로 써볼 수 있습니다.

팀플·공모전·동아리처럼 **모두가 같은 위치에서 참여하는** 대학생 팀을 위한 서비스입니다.
AI 회의록은 회의 한 건을 잘 남기는 데서 멈추지만, MeetFlow는 **회의가 쌓일수록 프로젝트가 선명해지는 것**을 목표로 합니다.

## 무엇을 할 수 있나

- **회의 분석** — 녹음·음성 파일·텍스트를 넣으면 요약, 안건별 회의록, 새 업무(담당자·마감일), 놓친 부분을 정리합니다.
- **회의 이어붙이기** — 지난 회의에서 끝나지 않은 업무를 이번 회의 분석에 함께 넣어, 해결됐는지 AI가 판단하고 지난 기록까지 갱신합니다.
- **N차 회의 정리** — 회의마다 차수가 붙고, 업무가 몇 차 회의에서 나왔는지 따라갈 수 있습니다.
- **트랙별 온보딩** — 팀플(강의계획서)·공모전(요강·심사기준)·동아리(정기모임·행사)마다 다른 마일스톤을 만듭니다.
- **프로젝트 마무리** — 회의 기록에서 사람별 역할·한 일·배운 점을 뽑아 경험 정리(자소서 소재)로 남깁니다.
- **구글 연동** — 업무 마감일을 캘린더에, 회의록을 Google Docs로, 다음 회의를 Meet 링크와 함께 잡습니다.

## 기술 스택

- HTML + CSS + 바닐라 JS (빌드 도구 없음)
- Firebase — Auth(구글 로그인), Firestore(데이터), AI Logic(Gemini)
- Google Calendar · Docs API
- GitHub Pages 배포

## 로컬에서 실행

```bash
python -m http.server 8000
```

→ http://localhost:8000 (파일을 더블클릭해 열면 구글 로그인이 동작하지 않습니다)
